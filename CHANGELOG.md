# Changelog

## 0.1.0 - 2026-09-27

- Initial public release.
- Email/password authentication against the Smart Coop cloud.
- Account device discovery.
- Open/close control through a Home Assistant cover entity.
- Cloud-reported open/closed, battery, online, charging and light/configuration diagnostics.
- Automatic re-authentication when the cloud session expires.
- Verified against a real Smart Coop C1 door.
